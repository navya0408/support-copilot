# Knowledge base

These are SHORT, GENERAL summaries of common US consumer-finance rules and good practice,
written for this learning project. They are not legal advice and not the policy of any
real company. For a real deployment, replace them with your company's own policy documents.

Format rules (the indexer depends on them):
- one `# Title` line at the top
- one or more `## Section` headings; each section becomes one searchable chunk
- keep each section under ~120 words so retrieval stays precise
- file name = the document id used in the evaluation set (backend/eval/eval_set.json)
